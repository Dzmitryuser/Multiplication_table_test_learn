# 📚 Multiplication-table

Интерактивное мобильное приложение для изучения таблицы умножения с красивым интерфейсом и встроенной клавиатурой.

## ✨ Возможности

### 🎯 Гибкие настройки
- **Диапазон изучения**: от любой цифры до любой (1-10)
- **Количество вопросов**: 5, 10, 15 или 20
- **Таймер**: отключен, 5, 10 или 15 секунд на вопрос
- **Режимы**: обучение (с подсказками) или экзамен

### 🎮 Интерактивный интерфейс
- Встроенная цифровая клавиатура
- Прогресс-бар и счетчик вопросов
- Обратный отсчет времени с визуальными предупреждениями
- Блокировка ввода во время показа подсказок

### 📊 Детальная статистика
- Процент правильных ответов с оценкой
- Подробный обзор всех вопросов и ответов
- Показ правильных ответов для ошибок
- Поздравления при отличных результатах

### 🎨 Современный дизайн
- Адаптивная мобильная верстка
- Градиентные фоны и анимации
- Эмодзи и визуальные эффекты
- Интуитивно понятный интерфейс

## 📱 Особенности использования

### Режим обучения
- Показывает правильный ответ при ошибке
- Мотивирующие сообщения
- Больше времени на изучение ошибок (2 секунды)
- Правильный ответ отображается красным цветом в поле ввода

### Режим экзамена
- Результаты только в конце
- Быстрый переход между вопросами
- Полная концентрация на решении

### Таймер
- Автоматический переход при истечении времени
- Красное предупреждение при ≤3 секундах
- Засчитывается как неправильный ответ
